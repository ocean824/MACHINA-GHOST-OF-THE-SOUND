# MACHINA & THE GHOST OF THE SOUND — Game Design Bible

## Identity
Cinematic traversal/action-adventure with African mythic/futurist identity, rhythm/sound as systemic force, environmental storytelling and agile movement. Inspiration from cinematic platform-adventure is translated into original mechanics/world/canon.

## Core loop
Enter district/ruin → traverse → investigate sonic/machine anomaly → environmental puzzle → rhythmic/sound manipulation → combat/escape → recover memory/sound fragment → alter machine/world behavior → narrative consequence.

## Movement
Responsive run/jump/vault/climb/wall-run/grapple/slide with authored cinematic set pieces. Titanfall Movement System is a starting accelerator; game-specific movement owns final feel/camera/animation.

## Sound mechanic
Sound is gameplay data: frequency/rhythm/intensity/source/direction can reveal geometry, synchronize machines, disrupt enemies, create traversal windows, reconstruct memories and alter encounters. Musical timing should reward rhythm without requiring professional musicianship.

## Combat
Fast melee/ranged/sonic hybrid with movement integration. Flexible Combat/Action RPG modules may accelerate implementation, but combat is authored around mobility and sound interactions rather than generic RPG loops.

## Narrative/world
Afrofuturist/mythic world where technology, ancestral memory and sound intersect. Narrative Pro 2 owns quest/dialogue/state foundation in Unreal. Interactive Story Plugin may supplement set-piece interactions if it does not duplicate canonical narrative state.

## Progression
Movement techniques, sonic abilities, machine interfaces, equipment and recovered memory. Upgrades expand expression rather than merely inflate damage.

## V1→V3
V1 proves movement, one sonic district, memory reconstruction, combat and a major boss/set piece. V2 expands traversal grammar, regions, factions and systemic sound. V3 completes cinematic campaign, challenge/endgame modes and AXIOM-native implementation.
