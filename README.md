# MACHINA & THE GHOST OF THE SOUND

Cinematic mythic action-adventure/platformer with African-rooted mythology, agile traversal, environmental puzzles and music/sound as a systemic force.

## Unreal foundation
Narrative Pro 2 + Ultra Game Template 1.3. Recommended layers: Titanfall Movement System as traversal reference/accelerator, Interactive Story Plugin where it complements rather than duplicates Narrative Pro, Flexible Combat/Action RPG modules for selected combat portions, Element Reaction for systemic world interactions, Boss AI/Animations, environments/VFX as appropriate. Fluid Flying may support specific spirit/air traversal sequences.

## Engine paths
Unreal is initial production/reference implementation. AXIOM-native build follows the same canonical gameplay/narrative/audio contracts.

## Gates
V1: polished traversal/combat/puzzle vertical slice + one mythic boss + sound mechanic. V2: complete campaign/world progression, enemy/boss roster, accessibility/performance. V3: expanded endgame/franchise systems + AXIOM/PYRAMID-native edition.
